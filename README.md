# DigestBot

Асинхронный Telegram-бот на aiogram 3, который собирает данные из нескольких внешних источников: курсы валют, новости с Хабра и случайный факт на русском.

Учебный проект: тренировка работы с asyncio, внешними API и Git.

## Команды

| Команда | Суть                              |
|---|-----------------------------------|
| `/start` | старт                             |
| `/help` | список команд                     |
| `/news` | последние 5 статей с Хабра        |
| `/fact` | случайный факт, переведённый на русский |
| `/currency` | курсы доллара и евро по данным ЦБ РФ |
| `/digest` | всё вышеперечисленное одним сообщением |

## Источники данных

- **Курсы валют:** [cbr-xml-daily.ru](https://www.cbr-xml-daily.ru/), неофициальный JSON API поверх данных ЦБ
- **Новости:** RSS-лента Хабра, парсинг через `feedparser`
- **Факты:** [uselessfacts.jsph.pl](https://uselessfacts.jsph.pl/), на английском
- **Перевод фактов:** DeepL API (нужен ключ)

## Технические решения

- **Одна `aiohttp.ClientSession` на всё приложение.** Создаётся при старте и пробрасывается в хендлеры, поэтому соединения переиспользуются.
- **Параллельные запросы.** В /digest три источника опрашиваются одновременно через `asyncio.gather`, поэтому общее время равно времени самого медленного из них, а не сумме.
- **Изоляция сбоев.** Каждый источник обёрнут в `safe_fetch`: таймаут и сетевые ошибки превращаются в объект `FetchError`, а не роняют команду. Если недоступен один источник, остальные в дайджесте всё равно отображаются.
- **Разделение слоёв.** Хендлеры только отвечают, сетевая логика в services.py, форматирование ответа в formatting.py.

## Структура

```
DigestBot/
├── bot.py             точка входа: Bot, Dispatcher, общая сессия, polling
├── config.py          токены (см. ниже)
├── endpoints.py       адреса API
├── services.py        получение данных по API
├── formatting.py      преобразование данных в красивый текст
├── utils.py           safe_fetch, FetchError, translate
├── handlers/
│   ├── common.py      /start, /help
│   └── digest.py      /news, /fact, /currency, /digest
└── requirements.txt   зависимости
```

## Запуск

Разработано на Python 3.14.

```
git clone https://github.com/AndreyMelanto/DigestBot.git
cd DigestBot

python -m venv .venv
source .venv/bin/activate    # Windows: .venv\Scripts\activate

pip install -r requirements.txt
```

Создайте в корне проекта config.py с этими токенами:

```
TOKEN = "токен от @BotFather"
DEEPL_API_KEY = "ключ DeepL API (есть бесплатный тариф)"
```

Запуск:

```
python bot.py
```

## Что бы я улучшил

Слабые места проекта.

1. Нет кэширования. Каждая команда заново отправляет запросы к API. Кэш на минуту-две снизил бы нагрузку на источники и ускорил бы ответы.
2. Ошибки не логируются. Пользователь видит понятное сообщение, но причина сбоя (`FetchError.message`) нигде не сохраняется.
3. Жёстко заданные данные. Валюты, число новостей зашиты в код, а не вынесены в конфигурацию.
4. Токены лежат в config.py. Надёжнее читать их из переменных окружения (.env и python-dotenv).
5. Нет Dockerfile.
6. Нет автотестов. Проверка только ручная.
